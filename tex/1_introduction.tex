\chapter*{Introduction}\label{introduction}
The aim of this project is to detect pairs of similar movies from the items in the Kaggle \textit{Letterboxd} dataset~\cite{Letterboxd2024}.

We begin by illustrating the methods that have been applied to study the similarity between movies (Chapter~\ref{methods}). We have opted for the LSH technique for cosine distance.

In Chapter~\ref{experiments} we describe the processes used to find movie pairs with a certain similarity. Seen the potential size of the dataset we have taken into account approaches targeted for massive datasets. 

We proceed by showing how we have applied these methods to the dataset itself in Section~\ref{experiments}, in addition to describing how the data has been pre-processed (Section~\ref{experiments_preProcessing}). We define an abstract experiment, specifying the parameters that characterize it and how it's computational cost scales with the size of the dataset.

Finally, in Chapter~\ref{results} we evaluate the various sets of similar movies that have been found by running the experiment with different parameters. The quality of these pairs is measured against a baseline set of similar items.
