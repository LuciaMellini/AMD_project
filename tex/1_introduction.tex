\chapter{Introduction}\label{introduction}
The aim of this project is to detect pairs of similar movies from the items in the Kaggle \textit{Letterboxd} dataset~\cite{Letterboxd2024}.

We begin by illustrating the methods that have been applied to study the similarity between reviews. In Chapter~\ref{methods} we describe the processed used to find review pairs with a certain cosine similarity. Seen the potential size of the dataset we have taken into account approaches targeted for massive datasets.

We proceed by showing how we have applied these methods to the dataset itself in Section~\ref{experiments}, specifically how we have vectorized the movie data (Section~\ref{experiments_preProcessing}). After this preliminary step we list the parameters that we have chosen to run the experiments.

Finally we show how the various sets of similar reviews that have been found through the different parameters. We evaluate the quality of these pairs by comparing them with a baseline similarity measure.
